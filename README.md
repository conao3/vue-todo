# vue-todo

A simple Todo application built with Vue.js.

![Screenshot](./images/ss1.png)

## Features

- Add and remove todo items
- Clean, minimal interface
- Built with Vue.js 2.x and Webpack

## Requirements

- Node.js (v12 or higher recommended)
- Yarn or npm

## Getting Started

### Installation

```bash
# Install dependencies
yarn install

# Or using npm
npm install
```

### Development

```bash
# Start the development server
yarn serve

# Or using npm
npm run serve
```

The application will open automatically in your default browser.

### Build

```bash
# Build for production
yarn build

# Or using npm
npm run build
```
